# 🚀 krs_hud

Modern HUD for FiveM built with **React + Mantine**, designed for **QBX Core** servers.

---

## 📦 Base Features (v1.0.0)

* 🧾 Server Info HUD
* ❤️ Player Status (health, armor, needs)
* 🚗 Basic Speedometer
* 🔫 Weapon Info
* 🗺️ Minimap integration
* ⚡ Optimized performance
* 🎨 Clean and modern UI

---

## 🚀 New in v1.1.0

### ✨ Added

* 🧩 **HUD Settings Menu**

  * Toggle:

    * Server Info
    * Player Status
    * Speedometer
    * Weapon State
    * Cinematic Mode

* 🎨 **Theme Color Selector**

* ⚙️ **Speed Unit Selector (KMH / MPH)**

* 🗺️ **Map State Options**

  * Always
  * Never
  * In Vehicle

* 🚴 **Bike HUD Support**

* 🚤 **Boat HUD Support**

* 🚗 Improved vehicle detection

## 📦 Requirements

* [ox_lib](https://github.com/overextended/ox_lib)
* QBX Core

---

## ⚙️ Installation

1. Download the script
2. Put it in your `resources` folder
3. Add in your `server.cfg`:

```cfg id="r4vcz1"
ensure ox_lib
ensure krs_hud
```

---

## 🖥️ UI Development (React)

### Install dependencies

```bash id="dxq13q"
npm i
```

### Run development environment

```bash id="v4j2sp"
npm run dev
```

### Build UI for FiveM

```bash id="1zazsa"
npm run build
```

👉 Output:

```id="7j8d0v"
web/build
```
